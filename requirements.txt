# ------------------------------------------------------------------------------
# 1. CORE BACKEND C++ LIBRARIES & FRAMEWORKS
# ------------------------------------------------------------------------------
# Crow C++ Framework:
#   High-speed, header-only C++ web microframework used to run the HTTP REST API
#   on port 8080 (serves /route endpoint for shortest path calculations).
crow>=1.0.0

# Asio C++ Library:
#   Cross-platform C++ library for network and low-level I/O programming.
#   (Automatically pulled as an internal dependency of Crow).
asio>=1.28.0

# System Threading:
#   POSIX Threads / C++17 std::thread required by Crow for multi-threaded requests.
threads (pthreads / C++17 STL)

# C++ Standard Library (C++17):
#   The backend code uses native C++17 STL features:
#   - <vector> (Adjacency List graph representation & fleet tracking)
#   - <queue>  (std::priority_queue for Min-Heap Dijkstra and Max-Heap Triage)
#   - <fstream>, <sstream> (CSV parsing for city_nodes.csv & city_edges.csv)
#   - <algorithm>, <climits>, <stdexcept>


# ------------------------------------------------------------------------------
# 2. C++ PACKAGE MANAGER (vcpkg)
# ------------------------------------------------------------------------------
# The project uses Microsoft vcpkg (manifest mode with vcpkg.json) to install Crow.
#
# Installation:
#   macOS / Linux:
#     git clone https://github.com/microsoft/vcpkg.git ~/vcpkg
#     ~/vcpkg/bootstrap-vcpkg.sh
#
#   Windows (PowerShell):
#     git clone https://github.com/microsoft/vcpkg.git C:\vcpkg
#     C:\vcpkg\bootstrap-vcpkg.bat
#     $env:VCPKG_ROOT = "C:\vcpkg"


# ------------------------------------------------------------------------------
# 3. BUILD TOOLS & COMPILERS
# ------------------------------------------------------------------------------

# ------------------------------------------------------------------------------
# 5. HOW TO BUILD & RUN IN VS CODE
# ------------------------------------------------------------------------------
# METHOD A: Via Terminal inside VS Code
#   1. Open integrated terminal in VS Code (`Ctrl + ~` or `Cmd + ~`).
#   2. Configure CMake with vcpkg toolchain:
#      macOS/Linux:
#        cmake -S . -B build-vcpkg -DCMAKE_TOOLCHAIN_FILE="$HOME/vcpkg/scripts/buildsystems/vcpkg.cmake"
#      Windows:
#        cmake -S . -B build-vcpkg -DCMAKE_TOOLCHAIN_FILE="$env:VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake"
#
#   3. Build the project:
#      cmake --build build-vcpkg
#
#   4. Start the backend API server:
#      macOS/Linux:  ./build-vcpkg/api_server
#      Windows:      .\build-vcpkg\Release\api_server.exe
#
# METHOD B: Via VS Code CMake Tools Extension (GUI)
#   1. Open project folder in VS Code.
#   2. In VS Code Settings (settings.json), set:
#      "cmake.configureSettings": {
#          "CMAKE_TOOLCHAIN_FILE": "${env:HOME}/vcpkg/scripts/buildsystems/vcpkg.cmake"
#      }
#   3. Select target: [api_server] from the bottom status bar.
#   4. Click "Build" or press [F7].
#   5. Click "Run" or press [Shift + F5].
